## 🚀 Cara Menjalankan di Komputer Lokal

1. Buka folder `aziel_portfolio_cinematic`.
2. Klik dua kali `index.html` pada browser apa pun (Chrome, Edge, Firefox).
3. Tanpa perlu `npm install`, Node.js, atau setup server rumit.

---

## 🌐 Cara Deploy ke Internet (Gratis & Cepat)

### Opsi 1: Vercel (Paling Direkomendasikan)
1. Buka [vercel.com](https://vercel.com) dan login dengan akun GitHub kamu.
2. Tarik (drag-and-drop) folder `aziel_portfolio_cinematic` ke dashboard Vercel, atau hubungkan repository GitHub kamu.
3. Klik **Deploy**. Website langsung online dengan link `aziel-portfolio.vercel.app` (dan HTTPS otomatis).

### Opsi 2: Netlify
1. Buka [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag-and-drop folder ini.
3. Dalam hitungan detik website akan langsung live di internet.

### Opsi 3: GitHub Pages
1. Push folder ini ke repository GitHub (misal: `portfolio` atau `azielganteng.github.io`).
2. Masuk ke **Settings > Pages**.
3. Pilih branch `main` (folder `/root`), lalu klik **Save**.

---

## ✉️ Cara Mengaktifkan Form Kontak (Formspree)

1. Buka [formspree.io](https://formspree.io) dan daftar akun gratis.
2. Buat Form baru, lalu salin **Form ID** kamu (misal: `xqkrwzop`).
3. Buka `index.html`, cari baris `<form id="contactForm" ... action="https://formspree.io/f/ID_FORMSPREE_LU">`.
4. Ganti `ID_FORMSPREE_LU` dengan Form ID kamu.
5. Sekarang setiap ada orang mengirim pesan melalui form kontak, pesannya langsung masuk ke email kamu!

*(Jika belum diganti, form kontak akan berjalan dalam Mode Demo tanpa error)*.
